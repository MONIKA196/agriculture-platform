# AgroSmart Platform

AgroSmart is a modern, AI-powered smart agriculture platform designed to help farmers optimize their crop yields through intelligent disease detection, weather insights, and expert advice.

## Features

- **Crop Disease Detection**: Instant diagnosis of plant diseases using AI.
- **Weather Insights**: Real-time weather data and forecasts tailored for farming.
- **AI Assistant**: Smart chatbot to answer all your agricultural queries.
- **Soil & Fertilizer Recommendations**: Get precise advice on soil health and fertilizer usage.

## Tech Stack

- **Frontend**: Vite, React, Tailwind CSS, Lucide Icons
- **Backend**: Supabase (Edge Functions, Auth, Database)
- **AI**: Gemini Vision & Chat Models

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```
